Click **File**, then **Open…**, and choose your file. To start from nothing, click **File**, then **New Workbook**.

## Open a file

1. Click **File** at the left of the tabs row.
2. Click **Open…**. Your system's file picker opens.
3. Choose the file and confirm.

The picker's first filter, **Spreadsheets**, shows files ending in `.xlsx`, `.xlsm`, `.xlsb`, `.ods`, `.csv`, `.tsv`, `.txt` and `.json`. Other filters narrow it to Excel workbooks, binary workbooks (`.xlsb`), OpenDocument spreadsheets (`.ods`) or CSV.

On the **Data** tab, **Get Data (Text/CSV)** opens the same file picker.

Two formats open with less than a full workbook. GridCraft 0.5.0 reads only the saved values of `.xlsb` and `.ods` files, not their formulas or formatting. For other formats, see [Which file formats can GridCraft open?](../faq/file-formats.md).

## Start a new workbook

1. Click the **Home** button at the left of the title bar. A **Start a new workbook** window opens.
2. Click **Blank workbook**, or one of the samples: **Household Budget**, **Quarterly Sales Dashboard** or **Gradebook**.

The window also lists your recent workbooks. Click one to open it. **Open…** in the same window opens the file picker. **File**, then **New Workbook** starts a blank workbook too.

## Close a workbook

Click **File**, then **Close**. If the workbook has unsaved changes, GridCraft asks "Do you want to save the changes you made to" the workbook, with **Don't Save**, **Cancel** and **Save**.
