Click **File**, then **Save**. A workbook that has no file yet opens the file picker so you can choose a name and folder.

## Save a workbook

1. Click **File**, then **Save**. The Save button in the title bar does the same.
2. If the workbook has never been saved, the picker opens. Type a name. If you leave off the extension, GridCraft adds `.xlsx`.

To save under another name, click **File**, then **Save As…**.

The window title shows **Edited** after the file name while the workbook has unsaved changes.

## Turn on AutoSave

The **AutoSave** switch is at the left of the title bar. Its tooltip reads "AutoSave: save after every change (workbooks saved to a file)". With it on, GridCraft saves a workbook shortly after you change it. It only does this for workbooks that already have an `.xlsx` file, so save a new workbook once first.

## Export a copy

1. Click **Share** at the right of the title bar.
2. Choose one of:
   - **Save a Copy as Excel Workbook (.xlsx)…**
   - **Export as CSV…**
   - **Export as Web Page (.html)…**
3. In the window that opens, type a path, or leave it empty and click **OK** to use the file picker.

**Export as CSV…** and **Export as Web Page (.html)…** write a copy and leave your workbook pointing at its own file. **Save a Copy as Excel Workbook (.xlsx)…** works like **Save As…**, so the workbook then belongs to the new file.
